# Kat 客户端 JSON / YAML 使用说明

- 文件仅选一个：`kat-client.json`、`kat-client.yaml`、`kat-client.yml`。无配置仍默认 JSON；多个并存会明确拒绝启动，保留一个再重试。不自动迁移旧 JSON。
- 配置页格式选择先产生草稿；可检查、编辑、取消。保存成功才切换扩展名并热应用；目标已存在不覆盖。已移除本地备份与自动快照，已有备份文件不删除；需要留存原文可先导出。
- 普通可视化编辑最小更新同一份原文，保留 YAML 注释、未改字段/标量和顺序；原文保存后反向更新所有表单。格式化是显式排版；YAML 转 JSON 会提示注释不保留。
- 导入只载入草稿（包括格式），保存才生效。导出只导出当前已保存的原文，保留正确扩展名；文件包含节点凭据，请妥善保管。
- 无效原文、保存或热应用失败，保留旧文件/旧运行代和草稿。不覆盖外部改文；重载不是偷偷读取并应用另一个文件的入口。
- 同端口保存保留现有代理流和网络开关；修改端口沿用已有的受影响路径恢复保护，不自动重新开启代理/TUN。
- YAML 仅支持 UTF-8、单文档、字符串键映射/数组与 JSON 兼容标量。不支持锚点、别名、合并键、自定义标签、多文档；重复键、错误类型、错误引用、超限输入明确报错。
- schema/字段/默认值均不变。不要直接导入整份 mihomo/Clash/Surge 配置；节点链接/订阅解析仍按原有能力独立使用。

桌面偏好、恢复journal、统计/历史文件仍独立，未改为 YAML。开发测试包未签名；本轮没有更新现网、Bero Windows 或开启代理/TUN。
